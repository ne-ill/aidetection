Three levels of scrutiny.

  • Real photograph analysis
  • Screenshot analysis
  • Basic image metadata
  • Confidence score
  • Evidence summary
Advanced

Investigate

  • Possible AI generator identification
  • Advanced EXIF metadata
  • C2PA provenance verification
  • GPS information if available and permitted
  • Editing history if recorded

  • Reverse image source investigation

03 — Method

Three passes. One answer.

1

Read the file’s metadata and provenance credentials.

2

Run an ensemble of AI-agent and deepfake detectors.

3

Fuse the evidence into a verdict with a confidence score.
